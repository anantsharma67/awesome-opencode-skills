# What Are OpenCode Skills?

OpenCode Skills are reusable workflow systems that teach AI coding agents how to perform specialized tasks consistently.

Skills can include:
- engineering workflows
- AI agent systems
- testing pipelines
- automation systems
- context engineering
- DevOps workflows
- frontend systems
- productivity workflows
- browser automation
- cloud infrastructure patterns

Each skill is packaged as a modular folder containing:
- `SKILL.md`
- structured workflows
- execution strategies
- setup instructions
- best practices
- production patterns

These skills are designed for:
- Claude Code
- OpenCode
- AI coding agents
- MCP systems
- autonomous workflows
- developer tooling ecosystems

# Skill Guidelines

Good skills should:
- solve real workflows
- remain production-oriented
- include setup instructions
- provide clear execution strategies
- remain modular and reusable
- avoid unnecessary complexity

Recommended structure:

```md
---
name: skill-name
description: Short description
---

# Overview
# Setup
# Workflow
# Best Practices
# Notes
```
