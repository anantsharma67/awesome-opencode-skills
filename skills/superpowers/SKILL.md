# Superpowers

## Overview

This skill enables Claude to help users think more clearly, structure ideas, and convert rough concepts into actionable plans.

It is designed for early-stage ideation, requirement gathering, and problem clarification.

---

## Setup

Before using this skill:

1. Define the general topic or project
2. Collect any rough notes or existing thoughts
3. Identify:
   - goals
   - constraints
   - uncertainties

Optional tools:
- Markdown notes
- Whiteboards
- Project management tools
- Documentation systems

---

## Inputs Required

- Rough ideas or project concepts
- Goals or intended outcomes
- Existing requirements (optional)

---

## When to Use This Skill

- Brainstorming project ideas
- Clarifying vague concepts
- Generating structured requirements
- Planning workflows
- Organizing scattered thoughts

---

## When NOT to Use

- Tasks with fully finalized requirements
- Highly repetitive execution workflows
- Pure implementation without planning

---

## Example Use Case

> “Turn a rough startup idea into a structured product plan”

Claude should:

1. Ask clarifying questions
2. Identify missing information
3. Structure requirements
4. Define scope and constraints
5. Generate an actionable roadmap

---

## Workflow

### 1. Idea Collection
- Gather rough concepts
- Identify goals and motivations
- Detect unclear assumptions

---

### 2. Clarification
- Ask targeted follow-up questions
- Resolve ambiguities
- Refine terminology

---

### 3. Structuring
Organize:
- requirements
- constraints
- priorities
- deliverables

---

### 4. Planning
- Define execution phases
- Break large tasks into smaller tasks
- Identify dependencies

---

### 5. Output Generation
Generate:
- requirement documents
- task breakdowns
- project summaries
- execution plans

---

## Output Expectations

- Clear project definition
- Structured requirements
- Actionable task list
- Reduced ambiguity

---

## Execution Strategy (for AI agents)

The agent should:

1. Detect ambiguity or incomplete ideas
2. Ask clarifying questions proactively
3. Transform vague inputs into structured outputs
4. Continuously refine understanding
5. Prioritize clarity and execution readiness

---

## Best Practices

- Avoid making assumptions too early
- Clarify goals before proposing solutions
- Break complex ideas into manageable components
- Iterate collaboratively

---

## Notes

- Good planning significantly reduces debugging and rework
- Structured requirements improve execution quality
- Clarity compounds over long projects
